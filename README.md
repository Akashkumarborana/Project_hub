# Antigravity Projects Hub & AI Studio 🚀

A modern digital marketplace and AI-powered custom code generator for software, web, and IT projects.

## 🌟 Features Included

1. **Pre-built Projects Marketplace (16 IT & Software Projects):**
   - Full Stack E-commerce, Hospital ERP, AI SaaS Studio, WebRTC Video Meetings, LMS Portal, Crypto Trading Bot, Food Delivery POS, Web Scrapers, Cloud Drive, Real Estate, Agile Kanban, Dev Portfolio, GST Billing ERP, and IoT Telemetry.
   - Categorized filters (Full Stack, Python/AI, Web App, SaaS, Cloud).
   - Real-time search & sorting.

2. **50% Instant Referral & Coupon Engine:**
   - Every user gets a unique referral code (`DEV50-PREMIUM`) & shareable URL.
   - 1-click WhatsApp and Telegram sharing.
   - 50% discount coupon applied at checkout with instant price deduction.

3. **"Antigravity AI Studio" (Custom Project Generator Box - Premium):**
   - Instant requirements synthesis box for users whose needs aren't met by pre-built projects.
   - Generates fully structured project code (HTML, JS, CSS, Python server, `run.bat`, `package.json`, and `README.md`).
   - Interactive code inspector tab to review generated code before unlocking.
   - Dynamic ZIP packaging via Python's `zipfile` module.

4. **1-Click PC Download & Setup Instructions:**
   - Visual 4-step setup guide on the website.
   - Downloaded projects include a dedicated `HOW_TO_RUN_ON_PC.txt` and Windows 1-click `run.bat` launcher.
   - Copy-paste terminal commands for Windows, Mac, and Linux.

## ⚡ How to Run

### Method 1 (1-Click on Windows):
Double-click `run.bat` in this folder. It will start the server and open your browser automatically.

### Method 2 (Terminal):
```bash
cd antigravity_projects_hub
python server.py
```
Then visit: **http://localhost:8000**
