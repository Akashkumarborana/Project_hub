## 🎨 UI Design System & Architecture

- **Handcrafted 3D Glassmorphism (`.glass3d`)**: Custom CSS engineered with `32px` backdrop blur, 7-layer specular shadows, ambient glowing radial mesh, and subtle egg-shell noise textures.
- **Client-Side ZIP Packaging (`JSZip` & `FileSaver.js`)**: 100% serverless ZIP compilation in the browser. No server backend required on GitHub Pages!
- **Interactive Sandbox Viewports**: Full multi-device preview switching between **Desktop (100%)**, **Tablet (768px)**, and **Mobile (375px)**.
- **Multi-Channel Payment Connections**:
  - **UPI & QR Scanner**: GPay, PhonePe, Paytm, BHIM, Cred with dynamic discount recalculation.
  - **Card & Net Banking**: Credit/Debit card form with 256-Bit SSL encryption badge.
  - **WhatsApp Direct Checkout**: Pre-formatted WhatsApp order message sent directly to Akash Borana.

## ⚡ How to Run Locally on Your PC

### Windows (1-Click Launch)
Double-click [`run.bat`](run.bat) or open PowerShell and run:
```powershell
python server.py
```
- **Local PC**: [`http://localhost:8000`](http://localhost:8000)
- **Phone on same Wi-Fi**: `http://192.168.1.4:8000`

### macOS & Linux
```bash
python3 server.py
```
